# LLM 기반 상대 AI

상대 트레이너가 어떤 기술을 쓸지 LLM 에게 물어보게 만든 기능. 안 켜면 그냥 기본 AI 가 돈다.

## 켜는 법

`.env` 에 두 줄 추가:

```
OPENAI_API_KEY=sk-...
POKEMON_LLM_AI=1
```

그리고 `make run`. 끝.

## 환경변수

| 변수 | 의미 |
|---|---|
| `POKEMON_LLM_AI` | `1` 이면 LLM 한테 물어봄. 비우면 기본 AI |
| `POKEMON_LLM_AI_DEBUG` | `1` = 어떤 기술 골랐는지 stderr 로 보여줌, `2` = 프롬프트 전체도 같이 보여줌 |
| `LLM_TIMEOUT_MS` | 한 번 호출에서 기다리는 최대 시간 (ms). 너무 길면 게임이 답답함. 보통 `8000` |
| `OPENAI_API_KEY` | OpenAI 키 |
| `LLM_BASE_URL` | 다른 백엔드(Ollama 등) 쓰고 싶을 때 |
| `LLM_MODEL` | 기본 `gpt-4o-mini` |

## 무슨 정보를 LLM 에 주는지

상대 턴이 올 때마다 아래를 한 번에 묶어서 보낸다.

- 양쪽 포켓몬: 이름, 타입, 현재/최대 HP, 상태이상, 능력치 단계
- 내 기술 1~N 번: 타입, 분류(물리/특수), 위력, **이 상황에서 예상 데미지**, **타입 상성 배수**, 능력 변화, 상태이상 확률

LLM 한테 시키는 건 딱 하나: **"1 ~ N 중 숫자 하나만 출력"**.
설명/문장 다 금지. 응답에서 첫 자릿수만 본다. 못 알아들으면 그냥 기본 AI 로 폴백.

## 작동 확인 결과

같은 상황을 LLM / 기본 AI 양쪽에 돌려서 비교한 결과.

| 상황 | LLM 선택 | 기본 AI 선택 | 평가 |
|---|---|---|---|
| 리자몽 vs 이상해꽃 (풀독) | 불대문자 (2배) | 불대문자 | OK |
| 피카츄 vs 나시 (풀/에스퍼) | 아이언테일 | 아이언테일 | OK (풀은 전기 0.5배라 강철이 더 셈) |
| 피카츄 vs 딱구리 (바위/땅) | **풀묶기 (4배)** | 풀묶기 | OK. 위력 95짜리 10만볼트가 0배인 함정을 피함 |
| 망나뇽 vs HP 15 후딘 | 드래곤크라크 (확킬) | 드래곤크라크 | OK. 셋업 기술 안 고름 |

핵심은 세 번째: 위력 숫자만 보면 10만볼트가 제일 세지만, 상대가 땅 타입이라 0배라는 정보를 받고 LLM 이 풀 기술로 갈아탔다. 단순히 위력 큰 거 찍는 게 아니라 상성을 본다는 뜻.

호출당 응답 약 1초. 기본 모델은 `gpt-4o-mini`.

## 동작 안 할 때 확인

- `POKEMON_LLM_AI_DEBUG=1` 켜고 실행. `[LLM] picked ...` 가 안 나오면 LLM 경로가 안 들어간 거.
- `env | grep POKEMON_LLM_AI` 로 환경변수 실제로 들어갔는지 확인.
- 키 / 네트워크 문제로 실패해도 게임은 안 멈춤. 기본 AI 로 알아서 돌아감.
